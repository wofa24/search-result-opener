# 搜索结果批量打开器

> Chrome 扩展 · 版本 3.7.1

在 Bing / Google 搜索结果页一键批量打开前 N 个链接，配合侧边栏导航快速浏览、截图保存。

---

## ✨ 功能特性

### 弹窗（Popup）

- 🔍 **料号 / 供应商自动填充** — 在搜索页打开弹窗时，自动从 URL 参数 `?q=` 提取搜索词，智能拆分为料号和供应商
- 🔎 **搜索引擎切换** — 支持 Bing / Google
- 📎 **文件格式过滤** — 可选不限制 / PDF / DOC / XLS / 图片
- 📌 **完全匹配** — 关键词加英文引号精确搜索
- 🔢 **打开数量** — 5 / 10 / 15 / 20 个或自定义数量
- ⚡ **快捷键设置区** — 弹窗内显示当前快捷键，一键跳转 Chrome 快捷键管理，配置快捷键每次打开数量（1-50，实时保存）
- 📋 **最近搜索** — 最多保存 10 条历史记录，点击快速填充料号
- 🚀 **确认打开** — 一键完成：当前标签页发起搜索 → 自动翻页提取结果 → 批量打开 → 显示侧边栏

### 侧边栏（Side Panel）

- 📋 **结果列表** — 显示所有打开的搜索结果页面（序号、网站图标、标题、域名）
- 🚩 **旗帜标记** — 标记有用页面，被标记的页面自动置顶排列，标记后自动跳转到下一个未标记页面
- ❌ **单页关闭** — 每个页面右侧有关闭按钮
- 🗑️ **关闭未标记** — 一键关闭所有未打旗帜的页面
- 📷 **保存截图** — 鼠标悬停显示蓝色遮罩 + 元素信息浮层（标签名 / 类名 / 像素尺寸），**滚轮或 ↑↓** 键切换父/子 DOM 层级，单击保存：
  - 图片 / Canvas / 视频元素直接提取像素数据
  - 非媒体元素优先提取 CSS 背景图，失败则用浏览器原生 `captureVisibleTab` 截图并裁剪到元素区域，任意网页均可成功
- ↑↓ **导航按钮** — 在页面间前后切换
- 🔄 **自动刷新** — 每 3 秒同步标签页状态，当前页面自动高亮居中

## ⌨️ 快捷键

| 操作 | 快捷键 / 方式 |
|------|--------------|
| 搜索页批量打开前 N 个结果 | `Alt + Shift + O`（可在 Chrome 扩展管理页自定义） |
| 退出截图捕捉模式 | `Esc` |
| 切换父/子元素层级 | `滚轮` 或 `↑` `↓` |
| 框选矩形区域截图 | 区域模式下**鼠标拖拽** |

> 弹窗内「快捷键设置」区可直接修改快捷键每次打开的页面数量（1-50，默认 10），修改实时保存。

## 🚀 安装方法

### Chrome / Edge（Chromium 内核）

1. 下载或克隆本仓库
2. 打开浏览器，访问 `chrome://extensions/`（Edge 为 `edge://extensions/`）
3. 开启右上角「开发者模式」
4. 点击「加载已解压的扩展程序」
5. 选择 `search-result-opener` 文件夹

> Edge 浏览器详细图文说明见 [安装说明.md](安装说明.md)。

## 📖 使用方法

### 方式一：弹窗操作

1. 点击工具栏的插件图标弹出窗口
2. 弹窗自动填充当前搜索页的料号和供应商（也可手动输入）
3. 选择搜索引擎、文件格式、打开数量
4. 点击「确认打开」— 插件自动搜索 → 多页提取 → 批量打开 → 显示侧边栏

### 方式二：快捷键（推荐）

1. 在 Bing 或 Google 搜索关键词
2. 在搜索结果页按 `Alt + Shift + O`
3. 插件自动提取前 N 个结果并批量打开（N 在弹窗中配置，默认 10）

### 侧边栏使用

1. 批量打开后侧边栏自动出现
2. 点击列表项切换页面，用 ↑↓ 按钮顺序浏览
3. 🚩 标记有价值的页面，它们自动置顶方便对比
4. 📷 点击「保存截图」进入捕捉模式，截取产品图片或规格参数
5. 🗑️ 浏览完毕后点击「关闭未标记」清理无用页面

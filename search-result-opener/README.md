# 搜索结果批量打开器

> Chrome 扩展 · 版本 3.5.0

在 Bing / Google 搜索结果页一键批量打开前 N 个链接，配合侧边栏导航快速浏览比较页面。

---

## ✨ 功能特性

### 核心功能
- 🔍 **批量打开搜索结果** — 一次性打开 5 / 10 / 15 / 20 或自定义数量的搜索结果页面
- 🗂️ **标签页组** — 自动将所有结果归入同一个标签页组，便于管理
- 📌 **侧边栏导航** — 打开后自动显示侧边栏，列出所有结果页，可快速切换
- ⌨️ **快捷键支持** — 在搜索页直接按快捷键（默认 `Alt+Shift+O`）批量打开，无需点开插件

### 侧边栏功能
- 列出所有已打开的结果页面（带序号、网站图标、标题、域名）
- 🚩 **旗帜标记** — 点击旗帜将页面标记为"找到图片的页面"，被标记的页面自动排列在列表最前方，支持多个标记
- ❌ **单页关闭** — 每个页面右侧有关闭按钮，可单独关闭
- 📷 **元素捕捉保存** — 类似 Save to Notion，点击后鼠标移到网页任意元素上显示蓝色遮罩，单击即可将该元素截图保存为 PNG
- 当前查看页面自动高亮并滚动居中显示
- ↑↓ 按钮在各页面间导航切换

### 缩略图导航
- 📑 **缩略图面板** — 显示所有打开页面的缩略图和基本信息，便于快速预览和导航

### 搜索选项
- 支持 Bing / Google 双搜索引擎
- 完全匹配模式（关键词加引号）
- 文件格式过滤（PDF / DOC / XLS / 图片）
- 最近搜索历史（最多保存 10 条，点击快速填充）

---

## ⌨️ 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Alt + Shift + O` | 在 Bing/Google 搜索页直接批量打开前 N 个结果 |

> 可在 Chrome 扩展管理页 → 快捷键处自定义修改。
> 插件弹窗内「快捷键设置」区可配置快捷键每次打开的页面数量。

## 🚀 安装方法

### Chrome 浏览器
1. 下载或克隆本仓库
2. 打开 Chrome，访问 `chrome://extensions/`
3. 开启右上角「开发者模式」
4. 点击「加载已解压的扩展程序」
5. 选择 `search-result-opener` 文件夹

### Microsoft Edge 浏览器
详见 [安装说明.md](安装说明.md) 文件。

## 📖 使用方法

### 方式一：点击插件图标
1. 在任意页面点击插件图标
2. 输入料号（关键词）和可选的供应商
3. 选择搜索引擎和打开数量
4. 点击「确认打开」

### 方式二：使用快捷键（推荐）
1. 先在 Bing 或 Google 搜索你要查询的关键词
2. 在搜索结果页按 `Alt + Shift + O`
3. 插件自动提取并批量打开前 N 个结果

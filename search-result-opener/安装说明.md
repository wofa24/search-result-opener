# Edge插件安装说明

## 快速安装指南

### 步骤1：打开扩展管理页面

1. 打开Microsoft Edge浏览器
2. 在地址栏输入：`edge://extensions/`
3. 按回车键

![扩展管理页面](https://via.placeholder.com/800x400?text=Edge+Extensions+Page)

### 步骤2：启用开发者模式

1. 在扩展管理页面，找到右上角的"开发人员模式"开关
2. 点击开关，将其**打开**（变为蓝色）

![开发者模式](https://via.placeholder.com/400x200?text=Developer+Mode+ON)

### 步骤3：加载插件

1. 点击页面左上角的"**加载解压缩的扩展**"按钮
2. 在弹出的文件选择窗口中，找到并选择 `search-result-opener` 文件夹
3. 点击"**选择文件夹**"按钮

![加载扩展](https://via.placeholder.com/600x400?text=Load+Unpacked+Extension)

### 步骤4：确认安装成功

安装成功后，您会看到：
- 扩展列表中出现"搜索结果批量打开器"
- 浏览器工具栏出现插件图标（蓝色搜索图标）
- 状态显示为"已启用"

![安装成功](https://via.placeholder.com/800x300?text=Extension+Installed)

## 开始使用

### 第一次使用

1. 打开Bing或Google搜索引擎
2. 搜索任意内容（如：ABC123）
3. 点击工具栏的插件图标
4. 在弹出框中点击"确认打开"

### 固定插件图标（推荐）

为了方便使用，建议将插件图标固定到工具栏：

1. 点击工具栏的"扩展"图标（拼图图标）
2. 找到"搜索结果批量打开器"
3. 点击右侧的"眼睛"图标，将其固定

## 常见问题

### Q1: 找不到"加载解压缩的扩展"按钮？

**解决方法**：
- 确保已开启"开发人员模式"
- 刷新页面后重试

### Q2: 提示"无法加载扩展"？

**解决方法**：
- 确保选择的是 `search-result-opener` 文件夹（不是其父文件夹）
- 检查文件夹中是否包含 `manifest.json` 文件
- 确保所有文件完整，没有缺失

### Q3: 插件图标是灰色的？

**解决方法**：
- 插件只在Bing或Google搜索结果页面可用
- 请先进行搜索，然后再点击插件图标

### Q4: 点击插件没有反应？

**解决方法**：
1. 打开 `edge://extensions/`
2. 找到插件，点击"详细信息"
3. 点击"重新加载"按钮
4. 刷新搜索结果页面后重试

### Q5: 侧边栏不显示？

**解决方法**：
- 确保勾选了"打开侧边栏导航"选项
- 或手动点击浏览器右上角的侧边栏按钮
- 检查Edge版本是否支持侧边栏API（建议使用最新版）

## 卸载插件

如需卸载插件：

1. 访问 `edge://extensions/`
2. 找到"搜索结果批量打开器"
3. 点击"移除"按钮
4. 确认删除

## 更新插件

当插件有新版本时：

1. 下载新版本的插件文件
2. 访问 `edge://extensions/`
3. 找到插件，点击"重新加载"按钮
4. 或先移除旧版本，再重新安装新版本

## 权限说明

插件需要以下权限：

| 权限 | 用途 | 必需性 |
|------|------|--------|
| tabs | 创建和管理标签页 | ✅ 必需 |
| tabGroups | 创建标签页组 | ✅ 必需 |
| sidePanel | 显示侧边栏 | ✅ 必需 |
| activeTab | 读取当前页面信息 | ✅ 必需 |
| storage | 保存配置 | ✅ 必需 |

**隐私说明**：
- 插件不会收集任何个人信息
- 所有数据仅保存在本地浏览器
- 不会向任何服务器发送数据

## 技术支持

如遇到其他问题：

1. 检查Edge浏览器版本（建议使用最新版）
2. 查看浏览器控制台是否有错误信息
3. 尝试重新安装插件
4. 联系开发者反馈问题

## 系统要求

- **浏览器**：Microsoft Edge（基于Chromium）
- **版本**：建议使用最新版本
- **操作系统**：Windows 10/11, macOS, Linux
